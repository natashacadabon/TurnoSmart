# Backend

API REST de TurnoSmart.

Stack previsto:

- Node.js
- Express
- TypeScript
- Prisma ORM
- Zod
- Supabase PostgreSQL
- Supabase Auth
- Gemini API

Responsabilidades:

- Autenticacion y perfiles.
- Negocios, servicios y clientes.
- Turnos, disponibilidad y eventos.
- Calculo de riesgo de no-show.
- Recordatorios por email.
- Integracion con Gemini para recomendaciones.
