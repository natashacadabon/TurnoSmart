# Frontend

Aplicacion web de TurnoSmart.

Stack previsto:

- Next.js
- React
- TypeScript
- Material UI
- CSS Modules
- TanStack Query
- React Hook Form
- Zod
- FullCalendar

Responsabilidades:

- Dashboard operativo.
- Agenda diaria y semanal.
- Gestion de clientes y servicios.
- Visualizacion del riesgo de no-show.
- Flujos de reserva, reprogramacion y cancelacion.
